# Shared Code Changes (Diff Patches)

This file tracks code changes via unified diffs.
Using diffs instead of full files saves tokens.

**How to add changes:**
1. Use `diff -u original.file modified.file` to generate a patch
2. Call `add_diff_patch()` with the diff content
3. Other agents can apply patches with `patch -p0 < patch.diff`
